# Algoritmos e Estruturas de Dados II (AEDs II) 🧱

Este repositório contém conteúdos e implementações da disciplina **AEDs II**, ministrada pelo professor **Max do Val Machado** na PUC Minas.

## 📚 Sobre a disciplina

O foco da disciplina é o estudo das **TADs (Tipos Abstratos de Dados)** e sua implementação em C/C++. A matéria fornece a base para resolver problemas de forma eficiente, utilizando estruturas de dados adequadas.

### Tópicos abordados:

- **Listas** (simples, duplamente encadeadas, circulares)
- **Pilhas e Filas** (estáticas e dinâmicas)
- **Árvores Binárias** (de busca, AVL)
- **Tabelas de Dispersão (Hashing)**
- Introdução à análise de complexidade e custo computacional

## 👨‍🏫 Professor

- **Max do Val Machado**
- Ênfase em implementação, uso prático das estruturas e clareza na construção dos algoritmos.


## 🎯 Objetivo

Aprofundar a lógica algorítmica através do domínio de estruturas de dados fundamentais e preparar os alunos para resolver problemas reais de forma estruturada e eficiente.
